
 
**Web
(World Wide web)**
-웹은 웹 브라우저와 웹페이지의 요청을 응답하는
웹 서버로 나뉨. 여기서 웹 브라우저는 클라이언트로 불리며 주로 인터넷을 사용하는 사람들을 의미하며 웹 서버는 서버로 불림

-클라이언트는 서버에게 요청을 하고 서버는 클라이언트의 요청에 알맞은 응답을 제공한다.

-주로 HTTP 또는 HTTPS 프로토콜을 사용함


**Network**
-컴퓨터들이 통신 기술을 이용하여 그물망처럼 연결된 통신 이용 형태를 의미

-노드(네트워크에 속한 컴퓨터 또는 통신 장비)들이 데이터를 공유할 수 있게 하는 디지털 전기통신망

-각종 통신 장비들이 서로 연결되어 데이터를 교환하며, 정보를 주고 받는 통신망

-종류
PAN: 가장 작은 규모의 네트워크, 개인 네트워크
LAN: 근거리 영역 네트워크
MAN: 대도시 영역 네트워크
WAN: 광대역 네트워크

-방식
유니 캐스트 : 특정 대상이랑 1:1 통신
멀티 캐스트: 특정 다수와 1:N 으로 통신
브로드 캐스트: 네트워크에 있는 모든 대상과 통신


-데이터 전달
  -패킷
    -큰 데이터를 작은 단위로 나누어 전송함
    -네트워크에서 데이터를 전달하기 위해 일정한 크기로 나눈 데이터 단위

  -무선통신
    -케이블을 사용하지 않고 전파 등의 무선 신호를 이용하여 데이터를 주고받는 통신 방식
    -무선 환경에서는 신호 세기, 거리, 장애물, 간섭 등의 영향을 받을 수 있음

-계층 구조
  OSI 7 Layer

   -네트워크 통신 과정을 7단계로 나눈 표준 모델
   -네트워크의 동작을 계층별로 구분하여 이해하기 위해 사용
   -7계층 응용 계층: 사용자에게 네트워크 서비스를 제공
   -6계층 표현 계층: 데이터 형식 변환, 압축, 암호화 등을 담당
   -5계층 세션 계층: 통신 연결의 생성, 유지, 종료를 담당
   -4계층 전송 계층: 송신자와 수신자 사이의 데이터 전송을 담당
   -3계층 네트워크 계층: IP 주소를 이용하여 데이터의 이동 경로를 결정
   -2계층 데이터 링크 계층: MAC 주소를 이용하여 같은 네트워크 안에서 데이터를 전달
   -1계층 물리 계층: 데이터를 전기·광·무선 신호로 전송


 TCP/IP 4계층
   -응용 계층: 사용자에게 네트워크 서비스를 제공
   -전송 계층: 장치 간 데이터 전송을 담당
   -인터넷 계층: IP주소를 이용하여 데이터를 목적지까지 전달
   -네트워크 엑세스 계층: 실제 네트워크를 통해 데이터를 전달

-IP 주소
  -네트워크에서 장치를 식별하기 위한 논리적인 주서
  -서로 다른 네트워크 사이에서 데이터를 전달할 때 사용
  -네트워크 환경에 따라 변경될 수 있음

-MAC 주소
  -네트워크 장치에서 부여되는 물리적인 주소
  -같은 네트워크 내부에서 장치를 식별하는 데 사용
  -네트워크 인터페이스를 구분하는 데 사용됨


-Port
  -하나의 컴퓨터에서 실행되는 여러 네트워크 서비스나 프로그램을 구분하기 위한 번호
  -같은 IP 주소를 사용하는 장치에서도 포트 번호를 통해 각각의 서비스를 구분함

-네트워크 장비
  -스위치
    -같은 네트워크 안의 여러 장치를 연결하는 장비
    -MAC 주소를 이용하여 데이터를 전달
    -목적지 MAC 주소에 맞는 장치로 데이터를 전달
    -ㅈ주로 OSI 2계층에서 동작
  -라우터
    -서로 다른 네트워크를 연결하는 장비
    - IP 주소를 이용하여 데이터가 이동할 경로를 결정
    -주로 OSI 3계층에서 동작함


-전송 계층
  -TCP
    -연결 지향형 프로토콜
    -데이터를 전송하기 전에 송신자와 수신자가 연결을 설정함
    -데이터가 정상적으로 전달되었는지 확인함
    -데이터의 순서와 오류를 관리함
    -신뢰성 있는 통신을 중요하게 함
  
  
  
  -UDP
    -비연결형 프로토콜
    -연결 설정 과정 없이 데이터를 바로 전송함
    -데이터가 정상적으로 전달되었는지 확인하지 않음
    -TCP보다 구조가 단순하고 빠름
    -신뢰성보다 전송 속도를 중요하게 함  





**인터넷(Internet)**
-전 세계 컴퓨터들을 하나로 연결하는 거대한 통신망을 의미

-네트워크가 모여 네트워크가 된 것임.

-쌍방향 통신을 제공
-시간과 장소를 제약받지 않고 언제든지 사용 가능
-익명성 제공
-TCP/IP를 기반으로 데이터를 주고받음



**Protocol**
-네트워크에서 장치들이 서로 통신하기 위해 지켜야 하는 규칙
-데이터의 형식, 전송 방법, 처리 방법등을 정함
-서로 다른 장치여도 같은 프로토
-HTTP, TCP, IP, DNS 등이 각각 다른 역할을 담당하는 프로토콜

-주요 프로토콜
  -DNS
    - 사람이 사용하는 도메인 이름과 IP 주소를 연결해주는 시스템
     -도메인 이름을 IP 주소로 변환하여 목적지 서버를 찾을 수 있도록 함

  -HTTP
    - 웹 브라우저와 웹 서버가 데이터를 주고받기 위해 사용하는 프로토콜
    -요청(Request)과 응답(Response) 방식으로 동작
    -기본적으로 데이터가 암호화되지 않음

  -HTTPS
    -HTTP에 보안 기능을 추가한 방식
    -TLS를 이용하여 클라이언트와 서버 사이의 통신을 암호화함
    -데이터 도청이나 변조 위험을 줄여줌



**정보보안**


**1.정보보안 기초
  - 정보와 정보시스템을 다양한 위협으로부터 보호하는 활동
  - 정보가 외부에 유출되거나 변경되거나 사용할 수 없게 되는 것을 방지하는 것이 목적
  - 정보보안의 기본 요소는 기밀성, 무결성, 가용성임
  
  
  
  -기밀성
    - 허가된 사용자만 정보에 접근할 수 있도록 하는 성질
    - 허가 되지 않은 사용자가 열람하는 것을 방지함
  -무결성
    - 정보가 허가되지 않은 방법으로 변경되거나 삭제되지 않도록 하는 성질
    - 데이터의 정확성과 신뢰성을 유지함
  -가용성
     - 허가된 사용자가 필요한 시점에 정보와 서비스를 정상적으로 이용할 수 있도록 하는 성질



**2.보안 위협과 위험**
  -취약점
    - 시스템, 프로그램, 네트워크 등에 존재하는 보안상의 약점
    - 공격자가 악용할 가능성이 있는 문제점

 -위협
     - 시스템이나 정보에 피해를 줄 가능성이 있는 요소
 
 -공격
     - 공격자가 취약점을 이용하여 시스템이나 정보를 침해하려는 실제 행위
 
 -악성코드
     - 시스템이나 데이터를 손상시키거나 악의적인 동작을 수행하고록 만들어진 프로그램
     - 정보 탈취, 시스템 파괴, 권한 획득 등의 목적으로 사용될 수 있음


**3.인증과 권한

-인증
  - 사용자가 누구인지 확인하는 과정
  - 사용자의 신원을 검증하는 과정
-인가
  - 인증된 사용자가 어떤 자원이나 기능을 사용할 수 있는지 결정하는 과정

-접근 통제
  - 사용자가 특정 시스템이나 데이터에 접근할 수 있는지를 관리하는 보안 방식
  - 인증과 인가를 사용하여 접근 권한을 관리함

-최소 권한
  - 사용자나 프로그램에 필요란 최소한이 권한만 부야하는 보안 원칙
  - 불필요한 권한으로 인한 피해를 줄이는 것이 목적


**4.암호화

-암호화
  - 원본 데이터를 알아볼 수 없는 형태로 변환하는 기술
  - 데이터가 외부에 노출되더라도 내용을 쉽게 확인할 수 없도록 보호함

-복호화
  - 암호화된 데이터를 다시 원해 데이터로 되돌리는 과정

-해시
  - 임의의 데이터를 일정한 길이의 값으로 변환하는 기숳
  - 일반적으로 해시값을 이용하여 원본 데이터를 다시 복원할 수 없음
  - 데이터 변조 여부 확인 등에 사용됨

-대칭키 암호화
  - 암호화와 복호화에 같은 키를 사용하는 방식
  - 처리 속도가 빠름
  - 암호화 키를 안전하게 전달하고 관리해야 함

-공개키 암호화
  - 공개키와 개인키라는 서로 다른 두 개의 키를 사용하는 방식
  - 공개키는 공개할 수 있고 개인키는 소유자가 보호해야 함
  - 대칭키 방식보다 일반적으로 처리 속도가 누림



**5.네트워크 보안


-방화벽
  - 네트워크를 통과하는 트래픽을 보안 정책에 따라 허용하거나 차단하는 시스템
  - 내부 네트워크와 외부 네트워크 사이의 통신을 통제함
  - 허가되지 않은 접근을 차단하는 역할을 함
-접근 제어
  - 사용자나 시스템이 특정 네트워크, 시스템, 파일 등에 접근할 수 있는지를 제한하는 보안 방식
  - 필요한 사용자에게만 필요한 권한을 제공하는 것이 목적


**6. 애플리케이션 보안

-입력값 검증
  - 프로그램이 입력되는 값이 허용된 형식과 범위에 맞는지 확인하는 과정
  - 잘못된 입력이나 악의적인 입력이 시스템 내부에서 처리되는 것을 방지함
-안전한 데이터 처리
  - 프로그램이 입력, 저장, 전송, 출력하는 데이터를 안전하게 처라하는 것
  - 민감한 정보가 불필요하게 노출되지 않도록 관리해야 함

**7.보안 운영

-로그
  - 시스템이나 프로그램에서 발생한 동작과 사건을 기록한 정보
  - 사용자 활동, 오류, 접속 기록 등을 확인할 수 있음
  - 장애 분석과 보안 사고 조사에 중요한 자료로 사용됨


-업데이트
  - 프로그램이나 시스템의 기능을 개선하고 문제점을 수정하기 위해 새로운 버전을 작용하는 작업

-패치
  - 소프트웨어에 발견된 오류나 보안 취약점을 수정하기 위해 제공되는 수정 사항



**8.보안 윤리

-보안 윤리
  - 정보보안 기술과 지식을 합법적이고 책임 있는 목적으로 사용해야 한다는 원칙
  - 보안 기술을 알고 있다는 이유만으로 임의의 시스템에 접근해서는 안 됨

-허가된 접근
- 시스템 소유자나 관리자로부터 명확하게 허가받은 범위 안에서만 접근해야 함
- 허가받은 범위를 넘어선 접근은 해서는 안 됨

-개인정보 보호
- 개인을 식별할 수 있는 정보를 안전하게 보호해야 함
- 개인정보를 목적 없이 수집하거나 외부에 노출해서는 안 됨

-책임 있는 보안 기술 사용
- 보안 기술은 시스템 보호, 취약점 개선, 사고 예방 등의 목적으로 사용해야 함
- 발견한 취약점을 악용하기보다 안전하게 보고하고 수정하는 방향으로 사용해야 함


**1.알고리즘


-알고리즘
  - 어떤 문제를 해결하기 위해 정해진 순서에 따라 수행하는 절차
  - 입력을 받아 처리한 뒤 원하는 결과를 출력함
  - 문제를 정확하고 효율적으로 해결하는 것이 목적


-알고리즘의 조건
  - 입력: 처리할 데이터가 존재할 수 있음
  - 출력: 처리 결과가 존재해야 함
  - 명확성: 각 단계가 분명해야 함
  - 유한성: 일정한 단계 후 종료되어야 함
  - 실행 가능성: 실제 수행 가능한 연산으로 구성되어야 함

-정확성
  - 알고리즘이 주어진 문제에 대해 올바른 결과를 만들어내는 성질 =
  - 정상적인 입력에 대해 예상한 결과를 출력해야 함

-효율성
  - 문제를 해결하는 데 필요한 시간과 메모리를 얼마나 효율적으로 사용하는지를 의미
  - 같은 결과를 내더라도 실제 시간과 자원 사용량이 적을수록 효율적임

-시간복잡도
  - 입력 크기가 증가할 때 알고리즘의 실행 시간이 얼마나 증가하는지를 나타내는 개념
  - 실제 시간보다 연산 횟수의 증가 정도를 중심으로 판단함

-Big-O 표기법
 - 입력 크기 n이 증가할 때 수행 시간이 어떻게 증가하는지를 표현함
 -  O(1): 입력 크기와 관계없이 일정
 - O(log n): 입력이 증가해도 수행 시간이 천천히 증가
 - O(n): 입력 크기에 비례
 - O(n log n): 비교적 효율적인 정렬에서 많이 나타남
 - O(n²): 입력이 증가할수록 수행 시간이 빠르게 증가
 - O(2ⁿ): 입력 증가에 따라 수행 시간이 매우 빠르게 증가


-순차탐색
  - 처음부터 마지막까지 데이터를 하나씩 확인하며 원하는 값을 찾는 방식
  - 데이터가 정렬되어 있지 않아도 사용 가능

-이분탐색
  - 정렬된 데이터에서 중간값을 기준으로 탐색 범위를 절반씩 줄여가며 원하는 값을 찾는 방식
  - 반드시 데이터가 정렬되어 있어야 함

-버블정렬
- 인접한 두 데이터를 비교하여 순서가 잘못되어 있으면 교환하는 방식
 - 이 과정을 반복하며 정렬

-선택정렬
- 정렬되지 않은 영역에서 가장 작은 값 또는 가장 큰 값을 찾아 알맞은 위치로 이동하는 방식

-삽입정렬
- 데이터를 하나씩 꺼내 이미 정렬된 부분의 알맞은 위치에 삽입하는 방식


-재귀
  - 함수가 자기 자신을 다시 호출하는 방식
  - 큰 문제를 같은 형태의 작은 문제로 나누어 해결할 때 사용
  - 반드시 종료 조건이 필요함
  - 호출이 많아질 경우 메모리 사용량 증가

-입력값 검증 
  - 프로그램에 입력된 값이 올바른 형식과 범위인지 확인하는 과정
  - 잘못된 입력으로 인한 오류를 예방하기 위해 사용함


-예외 처리
  - 프로그램 실행 중 발생할 수 있는 오류 상황을 처리하는 방법
  - 오류가 발생해도 프로그램이 비정상적으로 종료되지 않도록 함



-코드를 말로 설명하기
 - 프로그램이 어떤 순서와 논리로 동작하는지를 설명하는 것
 - 입력 → 처리 → 조건 판단 → 반복 → 출력 순서로 설명하면 이해하기 쉬움
 - 단순히 코드 문법을 읽는 것이 아니라 왜 그렇게 작성했는지를 설명하는 것이 중요함



**2. 자료구조

-자료구조
 - 데이터를 효율적으로 저장하고 관리하기 위한 방법
 - 데이터의 저장 방식에 따라 검색, 추가, 삭제 등의 성능이 달라짐
 - 문제에 맞는 자료구조를 선택하는 것이 중요함

-리스트
 - 여러 개의 데이터를 순서대로 저장하는 자료구조
 - 각 데이터는 위치를 가지며 순서가 유지됨
 - 데이터의 추가, 삭제, 수정, 탐색이 가능함

-스택
- 데이터를 한쪽에서 넣고 같은 쪽에서 꺼내는 자료구조
- 마지막에 들어온 데이터가 가장 먼저 나오는 구조
- LIFO
   Last In First Out
   후입선출 방식

-큐
- 한쪽에서 데이터를 넣고 반대쪽에서 데이터를 꺼내는 자료구조
- 먼저 들어온 데이터가 먼저 나오는 구조
- FIFO
  First In First Out
  선입선출 방식









# 네트워크 기초

1. 네트워크, 인터넷, 웹의 차이
    
    네트워크는 여러 장치가 연결된 통신망이고, 인터넷은 전 세계의 여러 네트워크가 연결된 통신망이며, 웹은 인터넷을 이용해 정보를 제공하는 서비스이다.
    
2. LAN과 WAN
    LAN은 가까운 지역에서 사용하는 네트워크이고, WAN은 넓은 지역을 연결하는 네트워크이다.
    
3. 프로토콜의 의미
    
    프로토콜은 네트워크에서 장치들이 서로 통신하기 위해 지켜야 하는 규칙이다.
    
4. OSI 7계층과 TCP/IP 4계층
    
    OSI 7계층은 네트워크 통신 과정을 7단계로 나눈 표준 모델이고, TCP/IP 4계층은 실제 인터넷 통신 구조를 4단계로 나눈 모델이다.
    
5. IP 주소, MAC 주소, 포트
    
    IP 주소는 네트워크에서 장치를 구분하는 논리적 주소이고, MAC 주소는 장치의 물리적 주소이며, 포트는 장치 안의 프로그램이나 서비스를 구분하는 번호이다.
    
6. 스위치와 라우터
    
    스위치는 같은 네트워크 안의 장치를 연결하고, 라우터는 서로 다른 네트워크를 연결한다.
    
7. TCP와 UDP
    
    TCP는 신뢰성을 중요하게 하여 데이터 전달 여부와 순서를 확인하고, UDP는 속도를 중요하게 하여 확인 과정 없이 데이터를 전송한다.
    
8. DNS
    
    DNS는 사람이 사용하는 도메인 이름을 IP 주소로 변환해 주는 시스템이다.
    
9. HTTP와 HTTPS의
    
    HTTP는 웹에서 데이터를 주고받는 프로토콜이고, HTTPS는 HTTP에 암호화 기능을 추가한 방식이다.
    
10. 패킷과 무선통신
    
11. 패킷은 네트워크에서 전송하기 위해 나눈 작은 데이터 단위이고, 무선통신은 케이블 없이 무선 신호를 이용해 데이터를 주고받는 방식이다.
    

# 정보보안

1. 기밀성, 무결성, 가용성 
    
    기밀성은 허가된 사용자만 정보에 접근하도록 하는 것이고, 무결성은 정보가 임의로 변경되지 않도록 하는 것이며, 가용성은 필요한 때 정상적으로 사용할 수 있도록 하는 것이다.
    
2. 취약점, 위협, 공격, 위험
    
    취약점은 시스템의 약점이고, 위협은 피해를 줄 가능성이 있는 요소이며, 공격은 취약점을 이용한 실제 침해 행위이고, 위험은 피해가 발생할 가능성을 의미한다.
    
3. 인증과 권한관리
    
    인증은 사용자가 누구인지 확인하는 과정이고, 권한관리는 사용자가 어떤 기능이나 자원을 사용할 수 있는지 결정하는 과정이다.
    
4. 암호화와 해시
    
    암호화는 데이터를 알아볼 수 없게 변환한 뒤 다시 복호화할 수 있는 기술이고, 해시는 데이터를 일정한 값으로 변환하여 일반적으로 원래 값으로 되돌리기 어렵게 하는 기술이다.
    
5. 대칭키와 공개키
    
    대칭키 암호화는 암호화와 복호화에 같은 키를 사용하고, 공개키 암호화는 공개키와 개인키 두 개를 사용한다.
    
6. 방화벽과 최소 권한  
    
    방화벽은 네트워크 트래픽을 허용하거나 차단하는 시스템이고, 최소 권한은 필요한 만큼의 권한만 부여하는 보안 원칙이다.
    
7. 악성코드  
    
    악성코드는 시스템이나 데이터에 피해를 주거나 악의적인 동작을 수행하도록 만들어진 프로그램이다.
    
8. 입력값 검증
    
    입력값 검증은 프로그램에 입력된 값이 허용된 형식과 범위에 맞는지 확인하는 과정이다.
    
9. 로그와 업데이트
    
    로그는 시스템이나 프로그램에서 발생한 동작과 사건을 기록한 정보이고, 업데이트는 프로그램이나 시스템의 기능과 보안을 개선하는 작업이다.
    
10. 보안 윤리
    
11. 보안 윤리는 보안 기술을 합법적이고 책임 있는 목적으로 사용하고 허가된 범위 안에서만 시스템에 접근해야 한다는 원칙이다.
    

# 알고리즘 / 자료구조

1. 알고리즘 
    
    알고리즘은 어떤 문제를 해결하기 위해 정해진 순서에 따라 수행하는 절차이다.
    
2. 정확성과 효율성  
    
    정확성은 알고리즘이 올바른 결과를 내는 성질이고, 효율성은 시간과 메모리를 얼마나 적게 사용하는지를 의미한다.
    
3. 순차탐색과 이분탐색
    
    순차탐색은 처음부터 하나씩 확인하며 찾는 방식이고, 이분탐색은 정렬된 데이터를 절반씩 나누며 찾는 방식이다.
    
4. 기본 정렬 
    
    기본 정렬에는 인접한 값을 비교하는 버블정렬, 가장 작은 값을 찾는 선택정렬, 알맞은 위치에 값을 넣는 삽입정렬이 있다.
    
5. 리스트
    리스트는 여러 데이터를 순서대로 저장하는 자료구조이다.
    
6. 스택과 큐 
    
    스택은 마지막에 들어온 데이터가 먼저 나오는 후입선출 구조이고, 큐는 먼저 들어온 데이터가 먼저 나오는 선입선출 구조이다.
    
7. 반복과 재귀
    
    반복은 같은 작업을 여러 번 수행하는 방식이고, 재귀는 함수가 자기 자신을 다시 호출하는 방식이다.
    
8. 시간복잡도
    
    시간복잡도는 입력 데이터의 크기가 증가할 때 알고리즘의 실행 시간이 얼마나 증가하는지를 나타내는 개념이다.
    
9. 입력값 검증과 예외 처리  
    
    입력값 검증은 입력된 값이 올바른지 확인하는 것이고, 예외 처리는 실행 중 오류가 발생했을 때 프로그램이 비정상적으로 종료되지 않도록 처리하는 것이다.
    
10. 코드를 말로 설명
    
11. 코드를 말로 설명한다는 것은 프로그램이 입력을 받아 어떤 처리를 하고 어떤 결과를 출력하는지 동작 순서에 따라 설명하는 것이다.
