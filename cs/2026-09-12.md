
 
**Web
(World Wide web)**
-웹은 웹 브라우저와 웹페이지의 요청을 응답하는
웹 서버로 나뉨. 여기서 웹 브라우저는 클라이언트로 불리며 주로 인터넷을 사용하는 사람들을 의미하며 웹 서버는 서버로 불림

-클라이언트는 서버에게 요청을 하고 서버는 클라이언트의 요청에 알맞은 응답을 제공한다.

-주로 HTTP 또는 HTTPS 프로토콜을 사용함


**Network**
-컴퓨터들이 통신 기술을 이용하여 그물망처럼 연결된 통신 이용 형태를 의미

-노드(네트워크에 속한 컴퓨터 또는 통신 장비)들이 데이터를 공유할 수 있게 하는 디지털 전기통신망

-각종 통신 장비들이 서로 연결되어 데이터를 교환하며, 정보를 주고 받는 통신망

-종류
PAN: 가장 작은 규모의 네트워크, 개인 네트워크
LAN: 근거리 영역 네트워크
MAN: 대도시 영역 네트워크
WAN: 광대역 네트워크

-방식
유니 캐스트 : 특정 대상이랑 1:1 통신
멀티 캐스트: 특정 다수와 1:N 으로 통신
브로드 캐스트: 네트워크에 있는 모든 대상과 통신


-데이터 전달
  -패킷
    -큰 데이터를 작은 단위로 나누어 전송함
    -네트워크에서 데이터를 전달하기 위해 일정한 크기로 나눈 데이터 단위

  -무선통신
    -케이블을 사용하지 않고 전파 등의 무선 신호를 이용하여 데이터를 주고받는 통신 방식
    -무선 환경에서는 신호 세기, 거리, 장애물, 간섭 등의 영향을 받을 수 있음

-계층 구조
  OSI 7 Layer

   -네트워크 통신 과정을 7단계로 나눈 표준 모델
   -네트워크의 동작을 계층별로 구분하여 이해하기 위해 사용
   -7계층 응용 계층: 사용자에게 네트워크 서비스를 제공
   -6계층 표현 계층: 데이터 형식 변환, 압축, 암호화 등을 담당
   -5계층 세션 계층: 통신 연결의 생성, 유지, 종료를 담당
   -4계층 전송 계층: 송신자와 수신자 사이의 데이터 전송을 담당
   -3계층 네트워크 계층: IP 주소를 이용하여 데이터의 이동 경로를 결정
   -2계층 데이터 링크 계층: MAC 주소를 이용하여 같은 네트워크 안에서 데이터를 전달
   -1계층 물리 계층: 데이터를 전기·광·무선 신호로 전송


 TCP/IP 4계층
   -응용 계층: 사용자에게 네트워크 서비스를 제공
   -전송 계층: 장치 간 데이터 전송을 담당
   -인터넷 계층: IP주소를 이용하여 데이터를 목적지까지 전달
   -네트워크 엑세스 계층: 실제 네트워크를 통해 데이터를 전달

-IP 주소
  -네트워크에서 장치를 식별하기 위한 논리적인 주서
  -서로 다른 네트워크 사이에서 데이터를 전달할 때 사용
  -네트워크 환경에 따라 변경될 수 있음

-MAC 주소
  -네트워크 장치에서 부여되는 물리적인 주소
  -같은 네트워크 내부에서 장치를 식별하는 데 사용
  -네트워크 인터페이스를 구분하는 데 사용됨


-Port
  -하나의 컴퓨터에서 실행되는 여러 네트워크 서비스나 프로그램을 구분하기 위한 번호
  -같은 IP 주소를 사용하는 장치에서도 포트 번호를 통해 각각의 서비스를 구분함

-네트워크 장비
  -스위치
    -같은 네트워크 안의 여러 장치를 연결하는 장비
    -MAC 주소를 이용하여 데이터를 전달
    -목적지 MAC 주소에 맞는 장치로 데이터를 전달
    -ㅈ주로 OSI 2계층에서 동작
  -라우터
    -서로 다른 네트워크를 연결하는 장비
    - IP 주소를 이용하여 데이터가 이동할 경로를 결정
    -주로 OSI 3계층에서 동작함


-전송 계층
  -TCP
    -연결 지향형 프로토콜
    -데이터를 전송하기 전에 송신자와 수신자가 연결을 설정함
    -데이터가 정상적으로 전달되었는지 확인함
    -데이터의 순서와 오류를 관리함
    -신뢰성 있는 통신을 중요하게 함
  
  
  
  -UDP
    -비연결형 프로토콜
    -연결 설정 과정 없이 데이터를 바로 전송함
    -데이터가 정상적으로 전달되었는지 확인하지 않음
    -TCP보다 구조가 단순하고 빠름
    -신뢰성보다 전송 속도를 중요하게 함  





**인터넷(Internet)**
-전 세계 컴퓨터들을 하나로 연결하는 거대한 통신망을 의미

-네트워크가 모여 네트워크가 된 것임.

-쌍방향 통신을 제공
-시간과 장소를 제약받지 않고 언제든지 사용 가능
-익명성 제공
-TCP/IP를 기반으로 데이터를 주고받음



**Protocol**
-네트워크에서 장치들이 서로 통신하기 위해 지켜야 하는 규칙
-데이터의 형식, 전송 방법, 처리 방법등을 정함
-서로 다른 장치여도 같은 프로토
-HTTP, TCP, IP, DNS 등이 각각 다른 역할을 담당하는 프로토콜

-주요 프로토콜
  -DNS
    - 사람이 사용하는 도메인 이름과 IP 주소를 연결해주는 시스템
     -도메인 이름을 IP 주소로 변환하여 목적지 서버를 찾을 수 있도록 함

  -HTTP
    - 웹 브라우저와 웹 서버가 데이터를 주고받기 위해 사용하는 프로토콜
    -요청(Request)과 응답(Response) 방식으로 동작
    -기본적으로 데이터가 암호화되지 않음

  -HTTPS
    -HTTP에 보안 기능을 추가한 방식
    -TLS를 이용하여 클라이언트와 서버 사이의 통신을 암호화함
    -데이터 도청이나 변조 위험을 줄여줌
