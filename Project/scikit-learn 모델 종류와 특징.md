
**1. 선형 회귀(Linear Regression)**  
→ 데이터를 가장 잘 설명하는 최적의 직선을 찾아 연속적인 숫자 값을 예측

**2. 로지스틱 회귀(Logistic Regression)**  
→ 데이터가 특정 범주에 속할 확률을 계산하여 분류

**3. K-최근접 이웃(K-Nearest Neighbors, KNN)**  
→ 새로운 데이터와 가장 가까운 K개의 데이터를 참고하여 예측

**4. 의사결정나무(Decision Tree)**  
→ 데이터를 여러 조건으로 계속 나누면서 최종 결과를 예측

**5. 랜덤 포레스트(Random Forest)**  
→ 여러 개의 의사결정나무를 만들고 결과를 종합하여 예측

**6. 서포트 벡터 머신(SVM)**  
→ 서로 다른 데이터들을 가장 잘 구분하는 최적의 경계선을 찾아 분류

**7. 나이브 베이즈(Naive Bayes)**  
→ 각 데이터가 특정 범주에 속할 확률을 계산하여 가장 가능성이 높은 범주로 분류

**8. K-평균 군집화(K-Means)**  
→ 비슷한 특징을 가진 데이터끼리 K개의 그룹으로 자동으로 묶음

**9. 그래디언트 부스팅(Gradient Boosting)**  
→ 이전 모델이 틀린 부분을 다음 모델이 계속 보완하면서 예측 성능을 높임
